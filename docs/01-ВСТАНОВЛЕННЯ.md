# 📥 Встановлення системи тестування

Детальна інструкція з встановлення.

---

## Вимоги

### Обов'язково
- Git
- Обліковий запис GitHub
- Сучасний браузер (Chrome, Firefox, Edge)

### Рекомендовано
- GitHub CLI (`gh`) - для розширених функцій
- Node.js 18+ - для автоматизованих тестів
- VS Code або інший редактор коду

---

## Встановлення Git

### Windows
```powershell
# Через winget
winget install Git.Git

# Або завантажте з https://git-scm.com/download/win
```

### macOS
```bash
# Через Homebrew
brew install git

# Або через Xcode Command Line Tools
xcode-select --install
```

### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install git
```

### Перевірка
```bash
git --version
# git version 2.x.x
```

## Створення репозиторію

### Крок 1: Створіть репозиторій на GitHub

1. Відкрийте https://github.com/new
2. **Repository name**: `my-test-project`
3. **Description**: `Система тестування`
4. Виберіть **Public** або **Private**
5. ✅ **Add a README file**
6. Натисніть **Create repository**

### Крок 2: Клонуйте репозиторій

```bash
git clone https://github.com/ВАШ_ЛОГІН/my-test-project.git
cd my-test-project
```

## Додавання файлів системи тестування

### Крок 1: Розпакуйте архів

```bash

```

### Крок 2: Скопіюйте файли


## Налаштування GitHub Actions

1. Відкрийте репозиторій на GitHub
2. Перейдіть **Settings** → **Actions** → **General**
3. У розділі **Actions permissions**:
   - Виберіть **Allow all actions**
4. У розділі **Workflow permissions**:
   - Виберіть **Read and write permissions**
   - ✅ **Allow GitHub Actions to create and approve pull requests**
5. Натисніть **Save**

## Перевірка встановлення

### ✅ Шаблони Issue
1. Відкрийте **Issues** → **New Issue**
2. Переконайтесь, що є 3 шаблони:
   - 🧪 Тест-кейс
   - 🏃 Тестовий прогін
   - 🐛 Баг з тестування

### ✅ Мітки
1. Відкрийте **Issues** → **Labels**
2. Переконайтесь, що є мітки для:
   - test-case, test-run
   - priority:critical, priority:high, тощо
   - status:passed, status:failed, тощо

### ✅ GitHub Actions
1. Відкрийте **Actions**
2. Переконайтесь, що є workflows:
   - Automated Test Suite
   - Generate Visual Report

### ✅ Інтерактивна панель
1. Відкрийте `dashboard/test-runner.html` у браузері
2. Переконайтесь, що панель завантажується
