Як виконувати тести та записувати результати.

| Спосіб | Найкраще для | Швидкість |
|--------|--------------|-----------|
| Інтерактивна панель | Ручне тестування | ⭐⭐⭐ |

## Спосіб 1: Інтерактивна панель (рекомендовано)

### Відкриття панелі

```bash
# macOS
open dashboard/test-runner.html

# Windows
start dashboard/test-runner.html

# Linux
xdg-open dashboard/test-runner.html

# Або просто відкрийте файл у браузері
```

### Інтерфейс панелі

```

│  🧪 GitHub Test Runner                    [New Run] [Export]│

```

### Кнопки статусу

| Кнопка | Значення | Опис |
|--------|----------|------|
| ✓ | Passed | Тест пройдено |
| ✗ | Failed | Тест не пройдено |
| ⏸ | Blocked | Тест заблоковано |
| ⏭ | Skipped | Тест пропущено |

### Процес тестування

1. **Відкрийте додаток** для тестування в окремому вікні
2. **Відкрийте панель** test-runner.html
3. **Клікніть на тест** щоб розгорнути кроки
4. **Виконайте кроки** в додатку
5. **Натисніть кнопку статусу** (✓, ✗, ⏸, ⏭)
6. **Додайте примітки** якщо потрібно
7. **Перейдіть до наступного тесту**

### Експорт результатів

1. Натисніть **"Export Report"**
2. Заповніть інформацію про прогін
3. Натисніть **"Download Report"** або **"Copy Markdown"**

## Спосіб 2: GitHub Issues

### Створення тестового прогону

1. **Issues** → **New Issue**
2. Виберіть **"🏃 Тестовий прогін"**
3. Заповніть форму:
   - ID прогону: `RUN-2024-001`
   - Версія: `v1.0.0`
   - Середовище: `Staging`
   - Область тестування
4. **Submit new issue**

### Виконання тестів

1. Відкрийте Issue тестового прогону
2. Виконуйте тести по черзі
3. Редагуйте Issue:
   - `- [ ]` → `- [x]` для виконаних
4. Додавайте коментарі з результатами:

```markdown
## Результати - 2024-01-20 14:30

**Тестувальник:** @username
**Браузер:** Chrome 120

| Тест | Статус | Примітки |
|------|--------|----------|
| TC-TODO-001 | ✅ Pass | |
| TC-TODO-002 | ❌ Fail | Див. #45 |
| TC-TODO-003 | ⏸️ Blocked | Чекаємо #44 |
```

### Створення бага

Якщо тест не пройшов:

1. **Issues** → **New Issue**
2. Виберіть **"🐛 Баг з тестування"**
3. Заповніть:
   - Пов'язаний тест-кейс: `#123` або `TC-TODO-002`
   - Тестовий прогін: `#456`
   - Кроки для відтворення
   - Фактичний vs очікуваний результат
4. Поверніться до тестового прогону та додайте посилання на баг

## Спосіб 3: CLI (командний рядок)

### Передумови

```bash
# Встановіть GitHub CLI
gh auth login
```

### Команди

```bash
# Створити тестовий прогін
./test-manager.sh create-run "Регресія Sprint 15" "v2.1.0" "Staging"

# Переглянути активні прогони
./test-manager.sh list-runs

# Оновити результат тесту
./test-manager.sh update-test 42 TC-TODO-001 passed "Все працює"

# Масове оновлення
./test-manager.sh bulk-update 42 passed TC-TODO-001 TC-TODO-002 TC-TODO-003

# Переглянути звіт
./test-manager.sh report 42
```

### Приклад сесії


## Спосіб 4: Автоматизоване тестування

### Встановлення

```bash
# Встановіть залежності
npm install

# Встановіть браузери
npx playwright install
```

### Запуск тестів

```bash
# Запустити всі тести
npm test

# Запустити з видимим браузером
npm run test:headed

# Запустити інтерактивний режим
npm run test:ui

# Запустити конкретний файл
npx playwright test tests/todo.spec.js

# Запустити конкретний тест
npx playwright test -g "TC-TODO-001"
```

### Результати


## Статуси тестів

| Статус | Emoji | Опис | Коли використовувати |
|--------|-------|------|---------------------|
| **Passed** | ✅ | Пройдено | Всі кроки успішні |
| **Failed** | ❌ | Не пройдено | Є відхилення від очікуваного |
| **Blocked** | ⏸️ | Заблоковано | Неможливо виконати (баг, середовище) |
| **Skipped** | ⏭️ | Пропущено | Свідомо пропущено (не актуально) |
| **Retest** | 🔄 | Перетестувати | Потрібно повторити |

## Підготовка до тестування

### Чеклист перед тестуванням

- [ ] Браузер оновлено до останньої версії
- [ ] DevTools відкрито (F12)
- [ ] localStorage очищено: `localStorage.clear()`
- [ ] Консоль очищена: `console.clear()`
- [ ] Мережа: вкладка Network відкрита
- [ ] Тестовий прогін створено
- [ ] Тест-кейси під рукою

### Очищення середовища

```javascript
// У консолі браузера (F12 → Console)

// Очистити localStorage
localStorage.clear()

// Очистити sessionStorage
sessionStorage.clear()

// Очистити cookies
document.cookie.split(";").forEach(c => {
  document.cookie = c.replace(/^ +/, "")
    .replace(/=.*/, "=;expires=" + new Date().toUTCString() + ";path=/");
});

// Оновити сторінку
location.reload()
```
